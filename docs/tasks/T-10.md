# T-10 Kalshi fetcher
Wave 1. Depends on: Wave 0.

## Goal
Fetch open Kalshi markets and prices from the public API, save raw responses, normalize into cards and price records.

## Read first
docs/build-requirements.md "Market card and price record" and "Failure behavior"; ADR-005; official docs at docs.kalshi.com (confirm endpoints and fields; record differences in docs/assumptions.md)

## Acceptance criteria
- Raw response saved before parsing; card raw_ref points to it.
- Normalizes Fed rate markets into subject, structured cutoff, deadline (UTC), decider and unclear_result using vocab.yaml; anything else stored as empty.
- Reads price fields in the units the API declares; buy_price per side from executable asks; empty book side stored as empty.
- Multivariate combo markets skipped and counted.
- Malformed records skipped, counted and logged; run completes (part of test 20).
- Out-of-vocabulary value stored as empty (part of test 17).
- Timeout and typed errors; a failed request saves the error in fetch_runs.
- internal/fetch/kalshi/NORMALIZATION.md lists every choice: which venue time is the deadline, how rules sentences map to unclear_result, how fees are determined, which records are skipped.
- Record at least one real Fed market into fixtures/kalshi/fed/ for test 16.

## Wave 1 gate (D-18)
Together with T-11, report at least one real Kalshi Fed market whose rules fit gt, gte, lt or lte and that pairs with a Polymarket US market. If none exists, stop and report.
