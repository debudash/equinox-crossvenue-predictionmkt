# T-20 Fetch and rebuild commands
Wave 2. Depends on: Wave 1.

## Goal
Wire both fetchers through the registry, run them independently, and implement rebuild.

## Acceptance criteria
- `equinox fetch` runs both fetchers concurrently with independent timeouts; one failing never stops the other.
- `equinox rebuild` re-normalizes saved raw responses through the same code path, without network (testkit transport fails any request).
- Required test: TestReq18.
- Writing commands (fetch, match, route, rebuild) take the run lock and record a cycle; refused with a reason while another writer holds it (test W7).
- Fetch summary prints saved and skipped counts per venue with skip reasons.
