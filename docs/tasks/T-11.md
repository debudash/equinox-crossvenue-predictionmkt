# T-11 Polymarket US fetcher
Wave 1. Depends on: Wave 0. Decision: D-16, amendment A9.

## Goal
Fetch open Polymarket US markets and prices from its public market data API (no API key), save raw responses, and normalize into cards and price records. The card `venue` value is `polymarket`.

## Read first
docs/build-requirements.md "Market card and price record", "Failure behavior" and amendment A9; ADR-005; official docs at https://docs.polymarket.us (public API at https://gateway.polymarket.us)

## Acceptance criteria
- Uses only the public read endpoints: market list, market by id or slug, order book or BBO, events. Confirm paths and fields against the docs and record differences in docs/assumptions.md.
- Prices are integer-encoded strings in the venue's declared units; convert to dollars from 0 to 1 using the exact decimal type. No float parsing.
- buy_price per side from the book's best ask for that side; an empty side is stored as empty.
- YES and NO identified by the market side label, never by position.
- Normalizes Fed rate markets into the shared vocabulary and structured cutoff; decision-bucket outcomes that need "equals" or "moved by" (for example "No change", "25 bps increase") are stored with an empty cutoff and never match.
- Raw responses saved before parsing; card raw_ref points to them.
- Malformed records skipped, counted and logged (part of test 20); out-of-vocabulary values stored as empty (part of test 17).
- Respects published rate limits; polling within the 2-minute price loop; backoff on rate-limit responses.
- Fallback per A9: the fetcher has a `polymarket_international` source behind the same interface only if the Wave 1 gate fails; not built unless needed.
- internal/fetch/polymarket/NORMALIZATION.md states that the source is Polymarket US and lists every normalization choice.
- Record the Fed market used for test 16 into fixtures/polymarket/fed/.

## Wave 1 gate (D-18)
Before Wave 2 starts, report at least one real Fed market on Polymarket US whose rules fit gt, gte, lt or lte, and the Kalshi market it should pair with. If none exists, stop and report; the fallback decision is made by the owner.
