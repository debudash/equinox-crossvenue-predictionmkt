# T-02 Fixtures and test kit
Wave 0. Depends on: T-01.

## Goal
Fixture layout and a fake HTTP transport so fetcher and integration tests never call a live venue.

## Acceptance criteria
- fixtures/<venue>/<scenario>/ holds raw responses keyed by request path, plus manifest.json.
- internal/testkit provides an http.RoundTripper that serves fixtures and fails on unknown requests.
- Fault scenarios via manifest: timeout, HTTP 500, malformed JSON.
- A fixed `as_of` constant and a temp SQLite helper for tests.
