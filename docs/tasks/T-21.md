# T-21 Read-only feed
Wave 2. Depends on: Wave 1 store contracts.

## Goal
Reddit-style read-only feed per build-requirements "Feed" and the approved wireframes (https://claude.ai/artifact/TghfanvCGFAfjUs5bsRk34).

## Acceptance criteria
- Feed handlers read only from internal/feed/cache: an immutable snapshot of the latest completed cycle built from SQLite, checked every cache_check_every, swapped atomically, previous snapshot kept.
- Pages carry their cycle number; "Load more" pages through that cycle's snapshot (test W6). Newer completed cycle shows the new-data banner.
- A failed or incomplete cycle is never shown (test W5).
- serve runs as its own process and never imports internal/watch; with watch stopped it keeps serving the last completed cycle and shows when it completed (test W10).
- Subreddit = category, post = venue event with venue flair, comments = markets with yes and no buy prices and priced_at, crosspost badge on same or opposite matches, score = volume_24h, bot reply = latest match and route records with reason and action verbatim.
- Sorts: Top, Closing soon, Matched. Filters: venue, category.
- Handlers only read; a test asserts no write methods are reachable from the feed package.
- Works without JavaScript.

## FILE OWNERSHIP
internal/feed/** (including internal/feed/cache/**), cmd/equinox/serve.go
