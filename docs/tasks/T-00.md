# T-00 Scaffold, Makefile, CI, guard, acceptance runner
Wave 0. Depends on: none.

## Goal
Go module with the AGENTS.md layout, make targets, CI, a guard, and an acceptance runner.

## Acceptance criteria
- `go build ./...` and `make test lint guard` pass on the skeleton.
- `make guard` fails if internal/match or internal/route contains "kalshi" or "polymarket" (case-insensitive), imports net/http, or calls time.Now; also fails if internal/card contains a venue name. A script test proves each case.
- `make acceptance` runs tests named `TestReq01_` to `TestReq20_` and prints a 20-row pass/fail/missing table; missing counts as fail.
- CI runs test, lint, guard on every PR.
- cobra root command with stub subcommands fetch, match, route, serve, rebuild.
