# T-13 Router
Wave 1. Depends on: Wave 0.

## Goal
Implement build-requirements "Routing" decision rules in order.

## Acceptance criteria
- Pure `Decide(match, side, prices, asOf, roles)`; runner loads the latest match record per pair and the latest price per needed card and side with priced_at not after as_of, then appends one route record.
- Prices older than price_max_age before as_of are empty; reason says "price is stale" and names which.
- Fees applied only when known on both venues; fee_applied recorded.
- Exact ties go to roles.reference_venue. No venue names in code.
- Reasons are plain sentences from fixed templates.
- Required tests: TestReq08 to TestReq15.
