# T-12 Matcher
Wave 1. Depends on: Wave 0.

## Goal
Implement build-requirements "Equivalence" exactly.

## Acceptance criteria
- Pure `Compare(a, b Card) MatchResult` with no I/O; a runner loads cards, compares only pairs with the same non-empty subject, logs card counts per subject, and appends one match record per compared pair.
- Never reads title or rules_text (guard plus a test with swapped titles).
- Reason names the first differing or empty field in fixed field order.
- Required tests: TestReq01 to TestReq07, and the matching half of TestReq17 (a card with an empty field matches nothing).
- Hand-built card fixtures only; no fetcher dependency.
